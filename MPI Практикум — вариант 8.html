Модуль 1: Процессы и их ранги

Основы MPI: запуск параллельной программы, ранг процесса, размер коммуникатора

В MPI одна и та же программа запускается сразу в нескольких процессах. Чтобы процессы вели себя по-разному, каждый из них узнаёт свой ранг (номер от 0 до K−1). Процесс с рангом 0 называют главным, остальные — подчинёнными.

ФункцияНазначение
MPI_Initначало параллельной части программы
MPI_Comm_rankузнать ранг процесса в коммуникаторе
MPI_Comm_sizeузнать количество процессов K
MPI_Finalizeзавершение параллельной части

MPIBegin6

Условие

В каждом процессе дано целое число N (> 0) и набор из N чисел. В подчиненных процессах четного ранга вывести сумму чисел из данного набора, в процессах нечетного ранга вывести среднее арифметическое чисел из данного набора, в главном процессе вывести произведение чисел из данного набора.

Пояснение: Процессы друг с другом не общаются: каждый обрабатывает только свои данные, а выбор действия зависит от ранга (0, нечётный, чётный).

Выполнение задания

Измените числа или число процессов и нажмите «Запустить».

Способ решения

  1. Инициализировать MPI (MPI_Init)
  2. Получить ранг процесса (MPI_Comm_rank)
  3. Ввести N и набор из N чисел, посчитать сумму и произведение
  4. Ранг 0 → вывести произведение
  5. Нечётный ранг → вывести среднее арифметическое
  6. Чётный ранг > 0 → вывести сумму
  7. Завершить MPI (MPI_Finalize)

mpi_begin6.c

#include <mpi.h>
#include <stdio.h>

int main(int argc, char *argv[]) {
    int rank, size, n;
    double a, s = 0, p = 1;
    MPI_Init(&argc, &argv);
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%lf", &a);
        s += a;
        p *= a;
    }
    if (rank == 0)
        printf("Процесс 0: произведение = %g\n", p);
    else if (rank % 2 == 1)
        printf("Процесс %d: среднее = %g\n", rank, s / n);
    else
        printf("Процесс %d: сумма = %g\n", rank, s);

    MPI_Finalize();
    return 0;
}

Компиляция и запуск:

$ mpicc mpi_begin6.c -o begin
$ mpirun -np 4 ./begin

Модуль 2: Обмен сообщениями между процессами

Блокирующие и неблокирующие пересылки между парами процессов

Процессы MPI имеют раздельную память, поэтому данные передаются сообщениями. Сообщение определяется отправителем, получателем, тегом и коммуникатором. Обычные MPI_Send и MPI_Recv блокирующие, а MPI_Sendrecv объединяет отправку и приём и помогает избежать взаимной блокировки.

ФункцияНазначение
MPI_Send / MPI_Recvстандартные блокирующие отправка и приём
MPI_Bsendотправка с буферизацией
MPI_Sendrecvодновременные отправка и приём
MPI_Sendrecv_replaceто же, но с одним общим буфером
MPI_Probe, MPI_Get_countузнать тип и размер сообщения до приёма
MPI_ANY_SOURCE, MPI_ANY_TAGприём от любого отправителя / с любым тегом

MPIBegin25

Условие

В каждом процессе дано вещественное число. С помощью функции MPI_Sendrecv_replace поменять порядок исходных чисел на обратный (число из процесса 0 должно быть передано в последний процесс, число из процесса 1 — в предпоследний процесс, …, число из последнего процесса — в процесс 0). В каждом процессе вывести полученное число.

Пояснение: Партнёр процесса с рангом r — процесс size−1−r. Оба обмениваются числами одним вызовом, поэтому взаимной блокировки нет. При нечётном K средний процесс сам себе партнёр и свой обмен пропускает.

Выполнение задания

Измените числа или число процессов и нажмите «Запустить».

Способ решения

  1. Получить ранг и размер коммуникатора
  2. Ввести своё число
  3. Вычислить партнёра: size − 1 − rank
  4. Если партнёр ≠ rank — вызвать MPI_Sendrecv_replace
  5. Вывести полученное число

mpi_begin25.c

#include <mpi.h>
#include <stdio.h>

int main(int argc, char *argv[]) {
    int rank, size;
    double x;
    MPI_Status st;
    MPI_Init(&argc, &argv);
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    scanf("%lf", &x);
    int partner = size - 1 - rank;
    if (partner != rank)
        MPI_Sendrecv_replace(&x, 1, MPI_DOUBLE,
                             partner, 0,   /* кому, тег */
                             partner, 0,   /* от кого, тег */
                             MPI_COMM_WORLD, &st);
    printf("Процесс %d: получено %g\n", rank, x);

    MPI_Finalize();
    return 0;
}

Компиляция и запуск:

$ mpicc mpi_begin25.c -o begin
$ mpirun -np 4 ./begin

Модуль 3: Операции редукции и производные типы

Коллективные вычисления над данными всех процессов, составные типы и упаковка

Редукция объединяет данные всех процессов в один результат с помощью операции (сумма, произведение, минимум, максимум и др.). Для составных данных используют производные типы MPI или упаковку MPI_Pack/MPI_Unpack.

ФункцияНазначение
MPI_Reduceредукция, результат в одном процессе
MPI_Allreduceредукция, результат во всех процессах
MPI_Scanпрефиксная редукция
MPI_Reduce_scatterредукция и раздача частей результата
MPI_MAXLOC / MPI_MINLOCзначение и ранг процесса, где оно найдено
MPI_Type_struct, MPI_Packпроизводные типы и упаковка данных

MPIBegin50

Условие

В каждом процессе дан набор из K + 5 целых чисел, где K — количество процессов. Используя функцию MPI_Reduce для операции MPI_MAXLOC, найти максимальное значение среди элементов данных наборов с одним и тем же порядковым номером и ранг процесса, содержащего это максимальное значение. Вывести в главном процессе вначале все максимумы, а затем — ранги содержащих их процессов.

Пояснение: Каждый элемент упаковывается в пару «значение — ранг» (тип MPI_2INT). Операция MPI_MAXLOC выбирает пару с наибольшим значением; при равенстве возвращается меньший ранг. Результат получает только процесс 0.

Выполнение задания

Измените числа или число процессов и нажмите «Запустить».

Способ решения

  1. Получить ранг и размер, ввести K+5 чисел
  2. Сформировать массив пар {значение, ранг}
  3. Вызвать MPI_Reduce с типом MPI_2INT и операцией MPI_MAXLOC, корень — 0
  4. В процессе 0 вывести все максимумы
  5. Затем вывести все ранги

mpi_begin50.c

#include <mpi.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct { int val; int rank; } Pair;

int main(int argc, char *argv[]) {
    int rank, size;
    MPI_Init(&argc, &argv);
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    int n = size + 5;
    Pair *in = malloc(n * sizeof(Pair));
    Pair *out = malloc(n * sizeof(Pair));
    for (int i = 0; i < n; i++) {
        scanf("%d", &in[i].val);
        in[i].rank = rank;
    }
    MPI_Reduce(in, out, n, MPI_2INT, MPI_MAXLOC, 0, MPI_COMM_WORLD);

    if (rank == 0) {
        for (int i = 0; i < n; i++) printf("%d ", out[i].val);
        printf("\n");
        for (int i = 0; i < n; i++) printf("%d ", out[i].rank);
        printf("\n");
    }
    free(in); free(out);
    MPI_Finalize();
    return 0;
}

Компиляция и запуск:

$ mpicc mpi_begin50.c -o begin
$ mpirun -np 4 ./begin

Модуль 4: Коллективные операции и коммуникаторы

Широковещание, сбор и раздача данных, группы процессов

Коллективные операции выполняются сразу всеми процессами коммуникатора: рассылка (Bcast, Scatter), сбор (Gather) и обмен «все со всеми» (Alltoall). Варианты с буквой v (Gatherv, Scatterv) работают с блоками разной длины. Группы процессов позволяют создавать новые коммуникаторы.

ФункцияНазначение
MPI_Bcastрассылка данных из одного процесса всем
MPI_Scatter / Scattervраздача частей массива
MPI_Gather / Gathervсбор данных в одном процессе
MPI_Allgather, MPI_Alltoallсбор и обмен во всех процессах
MPI_Comm_group, MPI_Group_inclсоздание групп
MPI_Comm_create, MPI_Comm_splitсоздание новых коммуникаторов

MPIBegin34

Условие

В каждом процессе дан набор из R + 2 целых чисел, где число R равно рангу процесса (в процессе 0 даны 2 числа, в процессе 1 даны 3 числа, и т. д.). Используя функцию MPI_Gatherv, переслать эти наборы в главный процесс и вывести полученные наборы в порядке возрастания рангов переславших их процессов (первым вывести набор, данный в главном процессе).

Пояснение: Наборы имеют разную длину, поэтому используется MPI_Gatherv: массив counts задаёт размер блока каждого процесса, массив displs — смещение блока в общем буфере главного процесса.

Выполнение задания

Измените числа или число процессов и нажмите «Запустить».

Способ решения

  1. Ввести R+2 чисел (R — ранг)
  2. В главном процессе заполнить counts[i] = i + 2
  3. Вычислить displs[i] — сумму предыдущих counts
  4. Вызвать MPI_Gatherv
  5. В процессе 0 вывести собранный буфер

mpi_begin34.c

#include <mpi.h>
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) {
    int rank, size;
    MPI_Init(&argc, &argv);
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    int cnt = rank + 2, a[100];
    for (int i = 0; i < cnt; i++) scanf("%d", &a[i]);

    int *counts = NULL, *displs = NULL, *buf = NULL, total = 0;
    if (rank == 0) {
        counts = malloc(size * sizeof(int));
        displs = malloc(size * sizeof(int));
        for (int i = 0; i < size; i++) {
            counts[i] = i + 2;
            displs[i] = total;
            total += counts[i];
        }
        buf = malloc(total * sizeof(int));
    }
    MPI_Gatherv(a, cnt, MPI_INT, buf, counts, displs, MPI_INT,
                0, MPI_COMM_WORLD);
    if (rank == 0)
        for (int i = 0; i < total; i++) printf("%d ", buf[i]);

    MPI_Finalize();
    return 0;
}

$ mpicc mpi_begin34.c -o begin
$ mpirun -np 4 ./begin

Модуль 5: Виртуальные топологии

Декартовы топологии и топологии графа

Виртуальная топология задаёт логическую схему связей между процессами (решётка, кольцо, граф) независимо от физического устройства. В декартовой топологии процессы расположены в узлах n-мерной решётки, а функция MPI_Cart_shift сама определяет соседей по выбранному направлению.

ФункцияНазначение
MPI_Cart_createсоздать декартову топологию
MPI_Cart_coords / Cart_rankкоординаты ↔ ранг процесса
MPI_Cart_shiftранги соседей для сдвига
MPI_Cart_subвыделение подрешёток
MPI_Graph_createтопология графа
MPI_PROC_NULL«несуществующий» сосед на границе решётки

MPIBegin95

Условие

В каждом подчиненном процессе дано вещественное число. Определить для всех процессов декартову топологию в виде одномерной решетки и осуществить простой сдвиг исходных данных с шагом −1 (число из каждого подчиненного процесса пересылается в предыдущий процесс). Для определения рангов посылающих и принимающих процессов использовать функцию MPI_Cart_shift, пересылку выполнять с помощью функций MPI_Send и MPI_Recv. Во всех процессах, получивших данные, вывести эти данные.

Пояснение: Одномерная непериодическая решётка: у процесса 0 нет предыдущего соседа, у последнего нет следующего. MPI_Cart_shift с шагом −1 возвращает source = rank+1 и dest = rank−1, а на границе подставляет MPI_PROC_NULL. Поэтому последний процесс ничего не получает.

Выполнение задания

Измените числа или число процессов и нажмите «Запустить».

Способ решения

  1. Создать топологию: dims[0] = size, periods[0] = 0 (MPI_Cart_create)
  2. Вызвать MPI_Cart_shift(cart, 0, −1, &source, &dest)
  3. Подчинённые процессы (ранг > 0) отправляют число в dest через MPI_Send
  4. Процессы с source ≠ MPI_PROC_NULL принимают число через MPI_Recv
  5. Вывести полученные данные

mpi_begin95.c

#include <mpi.h>
#include <stdio.h>

int main(int argc, char *argv[]) {
    int rank, size, src, dst;
    double x = 0, y;
    MPI_Comm cart;
    MPI_Status st;
    MPI_Init(&argc, &argv);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    int dims[1] = { size }, periods[1] = { 0 };
    MPI_Cart_create(MPI_COMM_WORLD, 1, dims, periods, 0, &cart);
    MPI_Comm_rank(cart, &rank);
    MPI_Cart_shift(cart, 0, -1, &src, &dst);

    if (rank > 0) scanf("%lf", &x);       /* данные только у подчинённых */
    if (rank > 0)
        MPI_Send(&x, 1, MPI_DOUBLE, dst, 0, cart);
    if (src != MPI_PROC_NULL) {
        MPI_Recv(&y, 1, MPI_DOUBLE, src, 0, cart, &st);
        printf("Процесс %d: получено %g\n", rank, y);
    }
    MPI_Finalize();
    return 0;
}

Компиляция и запуск:

$ mpicc mpi_begin95.c -o begin
$ mpirun -np 4 ./begin
